# Calculadora de Média Escolar

Este projeto é um programa simples desenvolvido em **Java** que calcula a média de três notas de um aluno e informa se ele foi aprovado ou reprovado.

## Objetivo

O objetivo do programa é praticar conceitos básicos da linguagem Java, como:

- Entrada de dados pelo teclado;
- Declaração de variáveis;
- Operações matemáticas;
- Estruturas condicionais (`if` e `else`);
- Exibição de informações no console.

## Como funciona

O programa solicita ao usuário três notas. Em seguida, calcula a média utilizando a seguinte fórmula:

```text
média = (nota1 + nota2 + nota3) / 3
